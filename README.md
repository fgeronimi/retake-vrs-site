# retake-vrs site

Counter-Strike 2 Valve Regional Standings, republished with each roster's factors, matches and winnings, and an audit showing that every published value can be recomputed.

This repository only holds the generated HTML, published on GitHub Pages. It is rebuilt and pushed by `make site` from the retake-vrs project; do not edit it by hand.

Model and standings: [Valve](https://github.com/ValveSoftware/counter-strike_regional_standings). Event data: HLTV.org, as credited by Valve. Not affiliated with Valve or HLTV.
