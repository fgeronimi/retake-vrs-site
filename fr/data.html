    Comment ça marcheLe voyage des données

    Classement du 2 nov. 2026 · généré le 2026-11-18 23:46 UTC

    D'où viennent les données, et où elles vont

    Avant que tu voies les points d'une équipe sur ce site, les chiffres font un long voyage. Le voici, étape par étape, comme une recette.

    1. 1

      Les équipes jouent des matchs

      Partout dans le monde, des équipes jouent des matchs dans des tournois. Certaines sur scène devant un public, d'autres en ligne depuis chez elles.

      Le nom pour les grandsLes tournois de Counter-Strike 2

    2. 2

      Quelqu'un les note

      Des sites notent chaque match : qui a joué, qui a gagné, et combien d'argent chaque équipe a remporté.

      Le nom pour les grandsHLTV pour Valve, Liquipedia pour OpenVRS

    3. 3

      On en fait une copie dans un coffre

      On copie ces listes dans un coffre. On n'écrit jamais sur la copie, comme ça on peut toujours revenir vérifier.

      Le nom pour les grandsBronze · Google Cloud Storage

    4. 4

      On range et on vérifie

      On met chaque morceau dans le bon tiroir et on vérifie que rien ne manque. Si quelque chose cloche, tout s'arrête.

      Le nom pour les grandsSilver · tables BigQuery et contrôles de qualité

    5. 5

      On fait les calculs

      On suit la recette de Valve elle-même pour donner des points à chaque équipe. Puis l'ordinateur joue les prochains tournois des milliers de fois pour voir qui pourrait être invité.

      Le nom pour les grandsGold · le modèle en Python et la simulation

    6. 6

      Un robot construit le site

      Deux fois par jour, un petit robot se réveille, cherche les nouveaux matchs et refait toutes les pages, en anglais et en français.

      Le nom pour les grandsJob Cloud Run à 06:00 et 18:00 UTC · GitHub Pages

    De beaucoup à quelques-uns

    Beaucoup de matchs entrent. Une poignée d'équipes ressortent avec un ticket pour le Major. Les barres sont à l'échelle.

    Les vieux matchs comptent moins

    Un match de la semaine dernière compte en entier. Un match d'il y a cinq mois compte juste un peu. Après six mois, il ne compte plus du tout : c'est comme s'il était tombé par la fenêtre.
